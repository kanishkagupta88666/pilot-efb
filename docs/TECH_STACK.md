# Technology stack

This page lists every technology the repository uses or plans to use, with the version that is declared, the version that was actually installed when the project was verified, and where that information comes from.

## How to read the versions

- **Declared** is the range written in a dependency file. It says what is allowed, not what you will get.
- **Installed** is the exact version observed during the verification run for this documentation.
  - Frontend versions come from `frontend/package-lock.json`, so `npm ci` reproduces them exactly.
  - Backend versions come from the Python environment used to run the tests. The backend has **no lockfile**, so a fresh `pip install` may select newer versions inside the declared ranges.
- **Not verified** means the repository contains no evidence for a version.

Verification environment: macOS, Python 3.14.0, Node.js 22.23.3, npm 10.9.9, Git 2.50.1.
